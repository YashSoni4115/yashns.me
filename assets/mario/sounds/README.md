# Mario Sound Effects

Place the following audio files in this folder for the game to use them:

| File         | Trigger                       |
| ------------ | ----------------------------- |
| `jump.mp3`   | Mario jumps                   |
| `pipe.mp3`   | Mario enters a pipe (warp)    |
| `victory.mp3`| Mario hits the mystery box    |

Optional bonus files (already wired up in `mario.js` but silent if missing):

| File         | Trigger                       |
| ------------ | ----------------------------- |
| `stomp.mp3`  | Mario stomps a goomba         |
| `death.mp3`  | Mario gets hit by a goomba    |

Any common audio format works (mp3, wav, ogg). Just match the filename.
